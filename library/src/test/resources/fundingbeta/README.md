Update Funding Address and Delete Funding Address have no documented example, so their fixtures follow the response schemas. Supplemental inline cases cover fiat and beneficiary address details, count and amount limits, unknown enum values, pending deposits without amounts, and on-chain withdrawal details. Request signatures are checked against digests computed with the signing helper of Kraken's [Funding (Beta) guide](https://docs.kraken.com/exchange/guides/rest/funding). All tests run locally without API keys or network calls, and create, change or delete no addresses, deposits or withdrawals.
