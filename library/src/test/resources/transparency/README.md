PreTrade and PostTrade have no response example in [Kraken’s Spot REST OpenAPI specification](https://docs.kraken.com/openapi/spot-rest.yaml), version `1.1.0`, retrieved on 2026-09-21, so their fixtures are assembled from the property examples of the response schemas, with the Digital Token Identifier of Bitcoin as the base asset DTI. Supplemental inline cases cover empty trade batches, unknown notations, order systems and sides, and extra precision prices. No test calls the Kraken API.
